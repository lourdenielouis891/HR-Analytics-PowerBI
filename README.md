## Project Overview

Developed an interactive HR Analytics Dashboard in Power BI to transform employee data into meaningful business insights. The dashboard provides visual analysis of employee status, workforce distribution, gender demographics, and average age trends, helping support data-driven decision-making through clear and engaging visualizations.

## Key Insights

* The majority of employees are currently active within the organization.
* Full-time employees represent the largest portion of the workforce.
* Employee distribution across different employment types is relatively balanced.
* Gender demographics show a diverse workforce composition.
* Average age trends remain consistent across employee categories.



## Dashboard Features

* Employee Status Analysis
* Employee Type Distribution
* Gender Distribution Visualization

* Interactive Charts and Graphs

## Business Questions Answered

* What percentage of employees are active versus terminated?
* Which employee type represents the largest workforce segment?
* How is the workforce distributed by gender?
* What are the average age trends across employee categories?
* How can HR data support workforce planning and decision-making?
